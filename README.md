# Omkar Borade — Portfolio

My personal portfolio website built with vanilla HTML, CSS, and JavaScript.

🌐 **Live Site:** https://OmkarBorade12.github.io

## Tech Stack
- HTML5 (semantic)
- Vanilla CSS (dark theme, glassmorphism, animations)
- Vanilla JavaScript (scroll effects, particle canvas, typing animation)

## Features
- Animated hero with particle network & typing effect
- Smooth scroll reveal animations
- Responsive & mobile-friendly
- Sections: About, Skills, Experience, Projects, Certifications, Contact
